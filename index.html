OFFLINE BY DESIGN

生产数据不离开电脑

OP Analysis 不需要账号，不连接分析服务器，不发送遥测，也不进行后台自动更新。导入的测试文件、规格和报告只在当前 Windows 用户环境中处理与保存。

  • 无云端上传文件内容不会发送到网站或第三方服务。
  • 无网络依赖安装后可在断网环境完成核心分析。
  • 手动更新新版本由用户从本网站下载并核对哈希。

INSTALLATION

安装与校验

正式版将提供 OV 证书签名和 SHA-256 校验值。

  1. 下载安装版推荐 Windows 10/11 x64 用户使用安装版。
  2. 检查发布者确认数字签名有效，且发布者名称与网站一致。
  3. 核对哈希正式版发布时公布
  4. 完成安装首次安装包含离线运行组件，文件较大属于正常情况。
